# AIDB Application Portfolio

This is a single-page Next.js portfolio site for Noel Santayana's AIDB Growth Engineer application pre-work. It hosts two shipped artifacts referenced from the written application: an episode share-leverage rubric with a scored receipt, and a packaging prototype for a recent AIDB episode.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
